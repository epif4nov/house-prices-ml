# 🏡 House Prices Prediction & Model Error Analysis

Репозиторий содержит исследовательский проект по анализу данных о недвижимости, конструированию признаков (Feature Engineering), обучению нескольких алгоритмов машинного обучения и подробному анализу их ошибок.

---

## 📌 Цель проекта

Основная задача — построить пайплайн машинного обучения для максимально точного прогнозирования стоимости объектов недвижимости, а также провести сравнительный анализ моделей и понять, на каких объектах алгоритмы ошибаются сильнее всего.

---

## 🛠 Используемый стек

- **Язык программирования:** Python 3.10+
- **Анализ и предобработка:** `pandas`, `numpy`
- **Визуализация:** `matplotlib`, `seaborn`
- **Машинное обучение:** `scikit-learn` (Linear Regression, Random Forest, Gradient Boosting), `lightgbm` / `catboost`
- **Среда разработки:** Jupyter Notebook
